02 / 06 — OAuth & Permissions

Le centre des droits et des tokens

Dans la console : Votre App → OAuth & Permissions. C'est ici que se définissent les droits du bot et que l'on récupère les tokens d'accès.

🔐 OAuth & Permissions
Screenshot
🖼️
Page OAuth & Permissions
Coller ici la capture complète : Bot Token Scopes, User Token Scopes, Install to Workspace
⚙️ Ce qu'on configure
  • Bot Token Scopes — droits du bot (ex: chat:write)
  • User Token Scopes — droits agissant au nom d'un utilisateur
  • Install to Workspace — bouton qui déclenche l'installation réelle
🔑 Ce qu'on récupère
  • Bot User OAuth Token — xoxb-...
  • User Token — xoxp-...
À retenir Les scopes définissent ce que le token a le droit de faire.
À retenir Le xoxb- est le token principal pour agir comme le bot.
03 / 06 — Event Subscriptions

Rendre le bot réactif

Dans la console : Votre App → Event Subscriptions. C'est ici que Slack apprend quoi vous envoyer, et où l'envoyer.

⚡ Event Subscriptions
Screenshot
🖼️
Page Event Subscriptions
Coller ici : Enable Events, Request URL, Subscribe to Bot Events
⚙️ Ce qu'on configure
  • Enable Events — active la fonctionnalité
  • Request URL — endpoint qui recevra les events (ex: webhook n8n)
  • Subscribe to Bot Events — liste des events écoutés

04 / 06 — Alignement

Events + Scopes = comportement réel

Le bot ne fonctionne que si les events souscrits et les scopes accordés sont alignés.

Comportement souhaité Event à souscrire Scope(s) nécessaire(s)
🔔 Réagir à une mention
le bot répond quand on le tag		 app_mention app_mentions:read  + souvent  chat:write
✉️ Répondre en message privé
conversation en DM avec le bot		 message.im Scopes DM adaptés (ex: im:history, chat:write)
📖 Lire les messages d'un canal
écoute passive d'un channel		 message.channels Scopes de lecture (ex: channels:history)

Vérifier que Slack est bien Slack

Dans la console : Basic Information → App Credentials → Signing Secret. Ce n'est pas un token d'accès.
